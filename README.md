# Лабораторна робота №1

**Дисципліна:** Клієнтські технології Web-програмування  
**Тема:** Налаштування середовища розробки: VS Code, Live Server, DevTools. Контроль версій та публікація статичного сайту  
**Виконав:** Гуменюк Андрій, група ІН-41/2  

## Опис проєкту
Навчальний проєкт присвячений налаштуванню середовища для клієнтської веброзробки та відпрацюванню базового циклу роботи: локальна розробка, перевірка через сервер розробки, контроль версій, публікація. Реалізовано персоналізовану вебсторінку з власним кольором-акцентом та унікальним ідентифікатором, що генерується скриптом при завантаженні.

**Що зроблено:**
- налаштовано VS Code, встановлено потрібні розширення, перевірено Node.js;
- створено структуру проєкту та персоналізовану сторінку (HTML, CSS, JS);
- ініціалізовано Git, налаштовано `.gitignore`, виконано послідовність комітів;
- досліджено роботу сторінки через DevTools (DOM, стилі, консоль, мережа, Local Storage, адаптивність);
- опубліковано проєкт через GitHub Pages.
